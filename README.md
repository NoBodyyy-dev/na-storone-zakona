# На стороне Закона

Сайт и боты записи на консультацию для адвокатской коллегии «На стороне Закона».

Клиент выбирает адвоката на сайте, переходит в Telegram или MAX и за несколько шагов записывается на свободное время. Адвокат получает уведомление, администратор видит заявки и статистику прямо в Telegram.

## Состав

| Папка | Что внутри |
| --- | --- |
| `client/` | Многостраничный сайт коллегии: адвокаты, услуги, цены, контакты, SEO (sitemap, robots, manifest) |
| `lawyers-bot/` | Telegram бот на TypeScript: Express, grammY, PostgreSQL без ORM, слои repository и service, миграции, Jest |
| `server/` | Боты для Telegram и MAX с общей логикой записи и почтовыми уведомлениями адвокатам |
| `deploy/` | Конфигурация nginx: раздача сайта, прокси к боту, HTTPS |

## Что умеет

- Запись кнопками: вид дела, адвокат, услуга с ценой, дата, время, подтверждение
- Переход с сайта сразу к нужному адвокату по ссылке
- Кнопка «Назад» на каждом шаге без мусора в чате
- Расписание по будням, выходные и нерабочие дни, скрытие слотов ближе двух часов
- Двойная запись на один слот исключена уникальным индексом в базе
- Уведомления администраторам и адвокатам о новых заявках
- Панель администратора в Telegram: консультации на сегодня, заявки за неделю, статистика по адвокатам

## Стек

TypeScript, Node.js, Express, grammY, MAX Bot API, PostgreSQL, nginx, Docker Compose, Let's Encrypt, Jest

## Запуск

```bash
cp lawyers-bot/.env.example lawyers-bot/.env
docker compose up -d --build
docker compose exec bot node dist/database/seeds/seed.js
```

Одна команда поднимает nginx с сайтом, бота и PostgreSQL. База наружу не публикуется, миграции применяются при старте контейнера. Подробная инструкция по серверу и сертификатам в [DEPLOY.md](DEPLOY.md).
